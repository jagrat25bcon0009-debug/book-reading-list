# Personal Book Reading List

A command-line application to add books, view the reading list, mark books as read, and remove entries. Data is saved between runs in `books.json`.

## Run
```bash
python3 main.py
```

## Concepts practiced
- JSON file storage
- Lists and dictionaries
- Functions, loops, and validation
- Working with file paths

## Privacy
The app stores data locally on your computer. Do not commit personal reading notes or other private information to a public repository.
